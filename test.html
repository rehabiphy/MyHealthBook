Android MCP Setup Guide

This guide enables Claude to interact directly with your Android devices via Android Debug Bridge (ADB), allowing for advanced mobile development workflows.

check_circle Prerequisites

  • desktop_windows
    Claude Desktop

    Installed and configured.

  • smartphone
    Android Studio

    With Emulator setup or Physical device connected.

  • code
    Python 3

    Installed with pip or uv package manager.

Configuration

1

Open Developer Settings

Launch Claude Desktop, navigate to Settings > Developer.

2

Edit Configuration

Open the claude_desktop_config.json file.

Config Paths

Mac: ~/Library/Application Support/Claude/claude_desktop_config.json
Windows: %APPDATA%\Claude\claude_desktop_config.json
3

Implementation

Add the following JSON configuration to register the Android MCP server.

JSON 
{
  "mcpServers": {
    "android-mcp": {
      "command": "uvx",
      "args": ["android-mcp"]
    }
  }
}
info
Setup Complete

Restart Claude Desktop to apply the changes. You can now prompt Claude to list installed apps or run ADB commands.
